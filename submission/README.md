# Submission Workspace

This folder contains material intended for the final project submission.

Contents:

- `final-report/latex/WaveFEM_Solver_Report.pdf`: compiled final report.
- `final-report/latex/report.tex`: LaTeX source for the final report.
- `assets/figures/`: selected plots for the report.
- `assets/tables/`: validation and convergence tables.
- `assets/paraview-screenshots/`: selected ParaView screenshots.

Generated solver output folders such as `output/`, `output/mpi-scaling/`,
`build/`, and `validation-output/` are intentionally ignored by Git.
