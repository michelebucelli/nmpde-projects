# Final Report Workspace

This folder contains the working material for the final project report.

Recommended reading order:

1. `latex/WaveFEM_Solver_Report.pdf`
2. `latex/report.tex`
3. `REPORT_OUTLINE.md`
4. `SUBMISSION_CHECKLIST.md`

The LaTeX report can be rebuilt with:

```bash
cd submission/final-report/latex
./build_report.sh
```

Keep final selected figures in:

- `../assets/figures/`
- `../assets/tables/`
- `../assets/paraview-screenshots/`
