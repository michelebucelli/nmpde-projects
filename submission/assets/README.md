# Report Assets

This folder is for report and presentation material produced by the group.

Suggested structure:

- `figures/`: generated plots selected for the report.
- `tables/`: Markdown or CSV tables selected for the report.
- `paraview-screenshots/`: screenshots exported from ParaView.

Keep generated solver data in `output/`, `output/mpi-scaling/` or
`validation-output/`. Put here only
selected images or small files that are useful for the report.
